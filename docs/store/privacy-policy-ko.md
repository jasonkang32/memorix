# Memorix 개인정보처리방침 초안

시행일: 2026년 7월 20일  
앱 이름: Memorix  
패키지명: `com.mebonsoft.memorix`

> 이 문서는 Google Play 등록을 위한 초안입니다. 실제 공개 전에는 회사/개인 사업자명, 연락처, 호스팅 위치, 최종 기능 범위를 확정해야 합니다.

## 1. 개인정보 처리 목적

Memorix는 사용자가 선택한 사진, 영상, 문서와 관련 메모, 태그, 날짜 정보를 기기 안에서 정리하고 검색할 수 있도록 제공되는 로컬 우선 기록 관리 앱입니다.

앱은 다음 목적을 위해 기기 내 데이터를 사용합니다.

- 사진, 영상, 문서 등록 및 미리보기
- Work / Personal 공간별 기록 관리
- 메모, 태그, 날짜, 위치 정보 입력 및 검색
- OCR 텍스트 인식 및 검색
- 숨긴 보관함, 앱 잠금, 생체인증 등 보안 기능
- 사용자가 직접 선택한 백업 파일 생성 및 복원
- Google Play 결제를 통한 Pro 이용권 구매/복원

## 2. 처리하는 정보

Memorix는 사용자가 앱에서 직접 선택하거나 입력한 정보를 기기 안에서 처리합니다.

처리될 수 있는 정보:

- 사용자가 선택한 사진, 영상, 문서 파일
- 파일의 촬영/생성 일시, 파일 크기, 미디어 유형 등 기본 메타데이터
- 사용자가 입력한 메모, 태그, 국가/지역, 날짜 정보
- OCR 기능 사용 시 이미지에서 추출된 텍스트
- 숨김 여부, 즐겨찾기 여부, 앨범/분류 정보
- 앱 잠금 설정, PIN 해시, 생체인증 사용 여부
- 언어 설정
- Google Play 결제 상태 및 Pro 이용권 보유 여부

## 3. 민감한 정보와 권한 사용

Memorix는 사용자의 명시적인 선택 또는 권한 허용이 있을 때만 관련 기능을 사용합니다.

### 사진 및 동영상 접근

앱에 사진/동영상을 등록하거나 공유 등록을 할 때 사용됩니다. Android 버전에 따라 사용자가 선택한 항목에만 접근할 수 있습니다.

### 카메라

앱에서 바로 사진을 촬영하여 기록으로 저장할 때 사용됩니다. 카메라가 없는 기기에서도 기존 파일 등록 기능은 사용할 수 있도록 카메라 하드웨어는 필수 기능으로 요구하지 않습니다.

### 생체인증

앱 잠금 또는 숨긴 보관함 접근 확인을 위해 사용됩니다. 생체정보 자체는 Memorix가 저장하거나 전송하지 않으며, Android 시스템 인증 결과만 사용합니다.

### 네트워크

현재 앱은 로컬 우선 구조를 지향합니다. 다만 Google Play 결제, Android/Google 라이브러리 동작, 향후 Pro 구매 확인 또는 기능 제공을 위해 네트워크 권한이 포함될 수 있습니다.

## 4. 정보 저장 위치

Memorix의 기록 데이터와 사용자가 등록한 파일 사본은 기본적으로 사용자의 기기 안에 저장됩니다.

백업 기능을 사용하는 경우, 사용자가 직접 선택한 위치에 백업 파일이 생성됩니다. 해당 백업 파일의 보관 및 공유 책임은 사용자에게 있습니다.

Memorix는 민감한 개인 기록의 의도치 않은 클라우드 백업을 줄이기 위해 Android 자동 앱 데이터 백업을 기본적으로 비활성화합니다.

## 5. 외부 전송 및 제3자 제공

Memorix는 사용자의 사진, 영상, 문서, 메모, 태그 내용을 자체 서버로 전송하지 않는 것을 기본 원칙으로 합니다.

다만 다음 경우에는 외부 서비스가 관여할 수 있습니다.

- Google Play 결제 처리 및 구매 상태 확인
- 사용자가 Android 공유 기능, 백업 파일 공유, 클라우드 저장소 등을 직접 선택하는 경우
- Google ML Kit 등 앱 내 기능 제공을 위한 라이브러리 사용. 최종 출시 전 사용되는 ML Kit 기능의 온디바이스/네트워크 처리 여부를 확인해 Data Safety에 반영합니다.

## 6. 보유 및 삭제

앱 내 데이터는 사용자가 앱에서 삭제하거나, 전체 초기화하거나, 앱을 삭제할 때 기기에서 제거될 수 있습니다.

Pro 이용권 상태가 변경되더라도 기존 로컬 데이터는 자동 삭제하지 않습니다. 무료 제한을 초과한 상태에서는 새 기록 추가가 제한될 수 있으나 기존 기록 열람은 유지됩니다.

## 7. 사용자의 선택권

사용자는 다음을 직접 수행할 수 있습니다.

- 앱 권한 허용/철회
- 기록 수정/삭제
- 태그 삭제
- 숨긴 보관함 관리
- 백업 생성 및 복원
- 전체 데이터 초기화
- 앱 삭제를 통한 로컬 데이터 제거

## 8. 아동 개인정보
