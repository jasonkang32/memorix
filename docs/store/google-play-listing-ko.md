## Full Description

```text
Memorix는 흩어진 사진, 영상, 문서를 Work와 Personal로 나눠 조용히 보관하는 로컬 우선 기록함입니다.

출장 사진, 영수증, 계약 자료, 가족 기록, 일상의 순간을 갤러리 안에서 잃어버리지 않도록 메모와 태그, 날짜, 위치 맥락으로 정리할 수 있습니다.

주요 기능

• Work / Personal 분리 보관
업무 자료와 개인 기록을 별도 공간으로 나눠 관리합니다.

• 사진·영상·문서 등록
사진, 영상, 문서를 기록 단위로 묶어 보관합니다.

• 태그와 메모
기록마다 태그와 메모를 남겨 나중에 빠르게 찾을 수 있습니다.

• 검색과 필터
메모, 태그, 날짜, 미디어 종류를 기준으로 필요한 기록을 찾습니다.

• 숨긴 보관함
민감한 기록은 일반 목록에서 숨겨 별도로 관리할 수 있습니다.

• 백업/복원
로컬 데이터를 백업 파일로 내보내고 다시 복원할 수 있습니다.

• 광고 없음
Memorix는 개인 기록을 다루는 앱입니다. 광고 없이 조용한 사용 경험을 지향합니다.

무료 버전은 기본 기록 관리 기능을 제공합니다.
Memorix Pro 평생 이용권을 구매하면 항목 제한 없이 문서, OCR 검색, 숨긴 보관함, 백업/복원, 태그 관리 등 고급 기능을 사용할 수 있습니다.

Memorix는 사용자가 선택한 파일을 기기 안에서 정리하는 로컬 우선 앱입니다. 민감한 개인 기록을 불필요하게 외부 서버로 전송하지 않는 방향을 지향합니다.
```
