# Work 미디어 등록 화면 + 타임라인 카드 리디자인

## 개요

Work 탭의 미디어 등록 흐름을 변경하고 타임라인 카드 UI를 인스타그램 스타일로 개선한다.

**핵심 변경 3가지:**
1. 저장 전 입력화면 (`MediaComposeScreen`) 신규 추가
2. 입력화면 UI — 사진/영상 미리보기 + 메모/태그/위치 입력 폼
3. 타임라인 카드 비주얼 리디자인

## 1. 흐름 변경

### 현재 흐름

```
FAB → 갤러리/카메라 선택 → DB 저장 → MediaDetailScreen(편집) → WorkScreen 복귀
```

### 변경 후 흐름

```
FAB → 갤러리/카메라 선택 → MediaComposeScreen(입력) → 저장 버튼 → DB 저장 → WorkScreen 복귀
```

저장이 사용자 행동(저장 버튼) 이후에 발생한다. `MediaDetailScreen`은 기존 미디어 편집 전용으로 유지.

## 2. MediaComposeScreen (신규)

### 레이아웃

단일 스크롤 폼. 사진만 필수, 나머지 항목은 모두 선택사항.

```
┌─────────────────────────────┐
│  ← 뒤로    미디어 등록    저장  │  AppBar
├─────────────────────────────┤
│  ┌─────┐ ┌─────┐ ┌─────┐  │
│  │ 📷1 │ │ 📷2 │ │ 📷3 │  │  선택된 미디어 썸네일 (가로 스크롤)
│  └─────┘ └─────┘ └─────┘  │  탭하면 풀스크린 미리보기
│              + 추가          │  미디어 추가 버튼
├─────────────────────────────┤
│  이벤트 날짜  2026-06-22 📅  │  DatePicker
├─────────────────────────────┤
│  메모                        │
│  ┌───────────────────────┐  │
│  │ 여러 줄 입력 가능...    │  │  TextField (multiline)
│  └───────────────────────┘  │
├─────────────────────────────┤
│  태그                        │
│  [출장] [현장] [+ 태그 추가]  │  ChipGroup + 추가 버튼
├─────────────────────────────┤
│  위치                        │
│  🌍 국가: 한국               │  EXIF 자동입력 or 수동
│  📍 지역: 서울               │
│  [GPS 자동 입력]             │  GPS 버튼
├─────────────────────────────┤
│  AI 추천 태그                │
│  [건물] [사무실] [회의]      │  ML Kit 결과, 탭으로 추가
└─────────────────────────────┘
```

### 입력 항목

| 항목 | 필수 | 자동 채움 | 설명 |
|------|------|-----------|------|
| 미디어 | ✅ | - | 1개 이상 선택 시 저장 버튼 활성화 |
| 이벤트 날짜 | ❌ | EXIF 촬영일시 | DatePicker로 수정 가능 |
| 메모 | ❌ | - | 여러 줄 텍스트 입력 |
| 태그 | ❌ | - | 기존 태그 선택 + 커스텀 추가 |
| 위치 (국가/지역) | ❌ | EXIF GPS → 역지오코딩 | 수동 입력 또는 GPS 버튼 |
| AI 추천 태그 | ❌ | ML Kit ImageLabeler | 탭하면 태그 목록에 추가 |

### 다중 선택 처리

사진/영상을 여러 개 선택하면 하나의 입력화면에서 공통 메모/태그/위치를 설정한다. 모든 미디어에 동일한 정보가 적용된다.

### 동작 상세

- **미디어 미리보기 영역**: 가로 스크롤 `ListView`. 각 썸네일은 80x80, 탭하면 `MediaViewerScreen`으로 풀스크린 미리보기. "X" 버튼으로 개별 제거 가능.
- **"+ 추가" 버튼**: `CaptureBottomSheet`를 다시 열어 추가 미디어 선택 가능.
- **EXIF 자동 채움**: 첫 번째 미디어의 EXIF에서 날짜/GPS를 읽어 자동 입력. GPS가 있으면 역지오코딩으로 국가/지역 변환.
- **AI 태그 추천**: 화면 진입 시 비동기로 ML Kit ImageLabeler 실행. `TagMappingService.map()`으로 한글 태그 변환 후 "AI 추천 태그" 섹션에 표시. 사용자가 탭하면 태그 목록에 추가.
- **저장 버튼**: `MediaSaveService.saveAll()`에 메모/태그/위치 정보를 함께 전달. 저장 완료 후 `Navigator.pop(context, true)`.
- **뒤로가기**: 입력 내용이 있으면 "작성 중인 내용이 사라집니다. 나가시겠습니까?" 다이얼로그 표시.

## 3. 타임라인 카드 리디자인

### 카드 구조

```
┌──────────────────────────┐
│ 🇰🇷 서울 · 현장           │  헤더: 위치 + 주요 태그
│ 6월 22일 (일) 10:30       │  서브헤더: 날짜·시간
├──────────────────────────┤
│                          │
│    이미지 그리드           │  1~3장 그리드 (아래 참조)
│                          │
├──────────────────────────┤
│ [출장] [현장점검] [건물]   │  태그 Chips
├──────────────────────────┤
│ 오늘 현장 분위기 점검...   │  메모 (2줄 미리보기)
│ 더보기                    │
├──────────────────────────┤
│ 📷 3장 · 🎬 1개           │  미디어 카운트 + 타입 요약
└──────────────────────────┘
```

### 이미지 그리드 레이아웃

**1장:**
```
┌──────────────────────────┐
│                          │
│       메인 이미지         │  풀 너비, 4:3
│                          │
└──────────────────────────┘
```

**2장:**
```
┌────────────┬─────────────┐
│            │             │
│   img1     │   img2      │  50/50 분할
│            │             │
└────────────┴─────────────┘
```

**3장 이상:**
```
┌────────────┬─────────────┐
│            │   img2      │
│   img1     ├─────────────┤  좌측 큰 이미지 + 우측 2장
│   (큰)     │   img3      │  4장+ 이면 우하단에 "+N" 오버레이
│            │   (+2)      │
└────────────┴─────────────┘
```

### 비주얼 개선 포인트

- **카드 배경**: `Card` with elevation 2, border radius 12
- **헤더**: 위치 + 주요 태그를 상단 배치, 날짜·시간은 서브헤더로
- **이미지 영역**: `ClipRRect`로 라운드 처리, 갭 2px
- **메모 미리보기**: `maxLines: 2`, `overflow: TextOverflow.ellipsis`, "더보기" 링크
- **미디어 카운트**: 하단에 아이콘 + 텍스트로 요약
- **날짜 구분선**: 날짜가 바뀌는 지점에 구분 헤더 유지 (현재와 동일)

### 카드 탭 동작

- **카드 탭**: `MediaDetailScreen`으로 이동 (편집)
- **카드 롱프레스**: `MediaViewerScreen`으로 이동 (풀스크린)
- **"더보기" 탭**: 메모 전체 표시 (in-place expand)
