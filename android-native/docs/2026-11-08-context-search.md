# Memorix 검색 개선과 후속 개발

## 개발 범위

Memorix는 BOSSKIT과 독립적으로 개발한다. 사진 원본의 기기 내 보관과 기존 Google Drive 연결을 유지한다.

기존 코드에 다중 미디어 등록·태그·온디바이스 한국어 OCR·PDF 내보내기가 구현되어 있으므로, 첫 개선은 이미 보관한 미디어를 다시 찾는 흐름에 집중한다.

## 이번 검색 개선

- 업무·개인 탭의 검색 범위를 제목, 메모, OCR, 태그, 국가, 지역, 원본 표시 파일명으로 확장한다.
- 공백으로 구분한 여러 키워드는 순서와 무관하게 모두 일치해야 한다. 서로 다른 필드에 나뉘어 있어도 검색된다.
- 예: 제목 `에어컨 교체`, 지역 `서울 강남`, 태그 `현장`인 기록을 `강남 교체 #현장`으로 찾는다.
- 대소문자를 구분하지 않으며, `*` 같은 문자는 업무·개인 탭 검색에서 와일드카드로 해석하지 않는다.
- 기존 보호 정책을 유지한다. 잠금·비밀 항목의 상세 내용은 일반 검색으로 노출하지 않는다.
- 전용 검색 화면에서는 기존 검색어·앨범·유형과 촬영/이벤트 날짜 범위를 조합한다. 기간만 선택해도 결과를 볼 수 있다.
- 날짜 범위는 시작일·종료일을 포함하며 기기의 현지 시간대를 사용한다. 등록일이 아니라 저장된 `takenAt` 기준이다. 한쪽 날짜만 지정할 수 있다.
- 업무·개인 탭의 부분 문자열 검색과 전용 검색 화면의 기존 FTS 검색 방식은 이번에 통합하지 않는다.

## 다음 단계 후보

1. 실제 업무 사진으로 검색 성공률과 등록 부담을 측정한다.
2. 기존 OCR 처리 상태·재시도와 태그 재사용 흐름을 확인한다.
3. 설명 포함 공유·PDF의 실제 사용성을 개선한다.
4. 사진·메모·태그가 다른 기기에 함께 복원되는지 검증한다.
5. 저장한 검색 조건과 유사 사진 검색은 반복 사용 수요를 확인한 뒤 추가한다.

실기기 사진 검색, Drive 인증·복원, Play 결제는 JVM 테스트나 APK 빌드만으로 검증됐다고 판단하지 않는다.
