# Memorix Android Native

새 Android Native 앱 작업 디렉터리입니다.

## 현재 포함 내용
- Jetpack Compose 4탭 앱 골격
- Room DB 엔티티/DAO 초안
- 로컬 저장 경로 규약(`StorageLayout`)
- 기본 import manager / worker stub

## 다음 구현 우선순위
1. Room + Hilt DI 연결
2. 실제 미디어 import UI 및 worker payload 설계
3. 홈 그리드와 최근 미디어 조회 연결
4. 상세/앨범/검색 화면 도메인 구현
